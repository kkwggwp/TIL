# JS
## 1. 호이스팅
- 호이스팅 : 코드가 실행되면 변수, 함수를 미리 저장해서 선언되기 전에 사용하더라도 문제가 되지 않음
- var는 호이스팅 되지만 let, const는 안됨

## 2. 자료형
```
// typeof로 null을 확인시 object로 나오는건 유명한 버그
let value = null;
console.log("value 자료형 : ", typeof value);
```
