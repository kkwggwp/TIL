# JS addEventLisner

## 1. 익명 화살표 함수
```javascript
const btn = document.getElementById('myBtn');

btn.addEventListener('click', (event) => {
  console.log('버튼이 클릭되었습니다!');
  console.log('이벤트 객체:', event); // event 객체를 통해 클릭 위치 등 추가 정보 활용 가능
});
```
> 코드가 짧고 직관적입니다.
> 상위 스코프의 this를 그대로 사용해야 할 때 유용합니다.

## 2. 별도의 함수 사용
```javascript
const btn = document.getElementById('myBtn');

function handleClick() {
  console.log('버튼 클릭!');
  // 특정 조건이 만족되면 이벤트 리스너를 제거
  btn.removeEventListener('click', handleClick);
}

btn.addEventListener('click', handleClick);
```
> btn.addEventListener('click', () => { ... }); 와 같이 익명 함수를 사용하면
> removeEventListener로 제거할 수 없습니다.
> 제거하려면 함수가 참조하는 메모리 주소가 동일해야 하기 때문입니다.

## 3. options 객체 활용
```javascript
// 버튼을 딱 한 번만 클릭할 수 있음
btn.addEventListener('click', () => {
  console.log('이 메시지는 한 번만 보입니다.');
}, { once: true });

// 스크롤 성능 향상
window.addEventListener('scroll', handleScroll, { passive: true });
```
> once: true: 이벤트가 한 번만 실행된 후 자동으로 제거됩니다.

> passive: true: 스크롤과 같은 이벤트에서 preventDefault()를 호출하지 않겠다고 브라우저에 알려주어, 스크롤 성능을 최적화합니다. (주로 scroll, touchmove 이벤트에 사용)

> capture: true: 이벤트를 버블링(하위 -> 상위) 단계가 아닌 캡처링(상위 -> 하위) 단계에서 감지합니다.
