YOLO와 객체 탐지의 핵심 개념 정리
이 문서는 CNN의 기본 원리부터 시작하여, 딥러닝 기반 객체 탐지 모델, 특히 YOLOv1이 어떻게 문제를 해결했는지, 그리고 그 성능을 어떻게 평가하는지에 대한 핵심 개념들을 설명합니다.

1. CNN의 기본 개념 🧠
**합성곱 신경망(Convolutional Neural Network, CNN)**은 이미지 인식 분야에 혁명을 일으킨 딥러닝 모델입니다. 인간의 시신경을 모방한 구조로, 이미지의 공간적 특징을 효과적으로 추출하고 학습합니다.

[CNN 아키텍처 이미지]

커널 (Kernel) / 필터 (Filter)
개념: 이미지의 특징을 추출하기 위한 작은 행렬(예: 3x3, 5x5)입니다. 커널이 이미지를 처음부터 끝까지 훑고 지나가며(슬라이딩) 합성곱(Convolution) 연산을 수행합니다.

역할: 각 커널은 특정 특징(수직선, 수평선, 특정 색상 조합, 질감 등)을 감지하도록 학습됩니다. 예를 들어, 어떤 커널은 '눈'의 특징을, 다른 커널은 '코'의 특징을 찾도록 특화될 수 있습니다.

패딩 (Padding)
개념: 합성곱 연산을 수행하기 전, 이미지의 가장자리에 특정 값(주로 0)으로 채워진 테두리를 추가하는 것입니다.

목적:

정보 손실 방지: 합성곱 연산을 거치면 이미지 크기가 줄어드는데, 가장자리의 중요한 특징 정보가 손실되는 것을 막아줍니다.

크기 유지: 출력 이미지(Feature Map)의 크기를 입력 이미지와 같거나 원하는 크기로 조절할 수 있습니다.

스트라이드 (Stride)
개념: 커널이 이미지를 슬라이딩할 때 한 번에 이동하는 칸의 크기입니다.

역할: Stride가 1이면 한 픽셀씩 촘촘하게 이동하며 특징을 추출하고, Stride가 2 이상이면 성큼성큼 이동합니다. Stride를 크게 하면 출력 이미지의 크기가 작아지며, 연산량을 줄이는 효과가 있습니다.

축소 샘플링 (Subsampling) / 풀링 (Pooling)
개념: 추출된 특징 맵(Feature Map)의 크기를 줄이는 과정입니다. 대표적으로 **최대 풀링(Max Pooling)**과 **평균 풀링(Average Pooling)**이 있습니다.

최대 풀링: 특정 구역(예: 2x2)에서 가장 큰 값(가장 활성화된 특징)만 남기고 나머지는 버립니다.

목적:

연산 효율성: 데이터의 크기를 줄여 계산량을 감소시키고 모델의 속도를 높입니다.

과적합 방지: 미세한 위치 변화에도 모델이 같은 특징으로 인식하게 하여(Translation Invariance) 지나치게 세부적인 것에만 집중하는 과적합을 방지합니다.

2. 초기 CNN과 깊어진 모델의 한계 😥
CNN의 한계
초기 CNN 모델들은 이미지 분류에서는 뛰어났지만, 하나의 이미지 안에 여러 객체가 있거나 객체의 위치까지 정확히 찾아야 하는 객체 탐지(Object Detection) 문제에는 바로 적용하기 어려웠습니다. 객체의 크기, 비율, 위치가 매우 다양했기 때문입니다.

깊어진 모델의 학습 문제: 기울기 소실 (Vanishing Gradient)
모델의 성능을 높이기 위해 층(Layer)을 깊게 쌓자 새로운 문제가 발생했습니다. 바로 기울기 소실(Vanishing Gradient) 문제입니다.

쉽게 말해, 모델의 맨 뒤(출력층)에서 계산된 오차(정답과의 차이)가 역전파(Backpropagation)를 통해 맨 앞(입력층)으로 전달되면서, 층을 거칠 때마다 점점 약해져 0에 가까워지는 현상입니다. 맨 앞쪽 층들은 오차 신호를 거의 받지 못해 가중치 업데이트가 제대로 이루어지지 않고, 결국 학습이 멈추게 됩니다. 이는 마치 긴 귓속말 게임에서 맨 앞사람이 메시지를 전혀 못 듣는 것과 같습니다.

이 문제는 후에 ReLU 활성화 함수 사용, 배치 정규화(Batch Normalization), **잔차 연결(Residual Connection)**을 사용하는 ResNet 같은 모델의 등장으로 상당 부분 해결되었습니다.

3. Backbone은 왜 필요한 걸까? 🏛️
**백본 네트워크(Backbone Network)**는 객체 탐지나 세분화(Segmentation) 같은 복잡한 작업을 수행하는 모델의 핵심 부분을 의미합니다.

역할: 이미지의 저수준(low-level) 특징(선, 질감)부터 고수준(high-level) 특징(형태, 의미)까지를 추출하는 특징 추출기(Feature Extractor) 역할을 합니다.

필요성: 좋은 특징 추출은 최종적인 탐지 성능에 결정적인 영향을 미칩니다. 일반적으로 ImageNet과 같은 대규모 이미지 분류 데이터셋으로 미리 학습된(pre-trained) 강력한 분류 모델(VGG, ResNet, EfficientNet 등)을 Backbone으로 사용합니다. 이를 통해 모델은 이미지에 대한 풍부한 이해를 가진 상태에서 객체 탐지라는 특정 작업을 학습하게 되므로, 학습 속도가 빠르고 성능도 훨씬 좋습니다.

4. YOLOv1의 혁신적인 접근 🚀
왜 한 번에 모든 걸 예측하려고 했을까?
기존의 객체 탐지 모델(R-CNN 계열)은 2-Stage Detector였습니다.

1단계 (Region Proposal): 객체가 있을 만한 후보 영역(Region)을 수천 개 찾아낸다.

2단계 (Classification): 각 후보 영역마다 분류(Classification)를 수행하여 어떤 객체인지 맞춘다.

이 방식은 정확도는 높았지만, 단계가 나뉘어 있어 매우 느렸습니다.

**YOLO (You Only Look Once)**는 이 문제를 해결하기 위해 "객체 탐지를 하나의 회귀(Regression) 문제로 보자!"라는 아이디어로 접근했습니다. 이미지를 딱 한 번만 보고, 바운딩 박스(Bounding Box)의 위치와 클래스(Class)를 동시에 예측하는 1-Stage Detector를 제안했습니다. 이 덕분에 압도적으로 빠른 속도를 구현할 수 있었습니다.

박스 크기 다양성은 어떻게 처리했을까?
YOLOv1은 박스의 크기와 비율 다양성을 처리하는 데 명확한 한계가 있었습니다.

이미지를 S x S 그리드(Grid)로 나눕니다.

각 그리드 셀은 자신이 예측할 객체의 중심점이 자신 안에 있을 때 그 객체를 탐지할 책임이 있습니다.

각 그리드 셀이 예측하는 바운딩 박스의 좌표(x, y, w, h)는 그리드 셀에 상대적인 값으로 학습됩니다. 예를 들어, w, h는 전체 이미지 크기에 대한 비율로 예측합니다.

이 방식은 구조가 단순하고 빠르지만, 하나의 그리드 셀이 제한된 수(기본 2개)의 박스만 예측할 수 있고 하나의 클래스만 가질 수 있어, 다양한 크기와 비율의 객체나 작은 객체들이 몰려있을 때 제대로 처리하지 못하는 단점이 있었습니다. (이후 버전인 YOLOv2부터 앵커 박스(Anchor Box) 개념을 도입하여 이 문제를 개선합니다.)

작은 물체를 효과적으로 탐지하기 위해 어떻게 했을까?
솔직하게 말해, YOLOv1은 작은 물체 탐지에 매우 취약했습니다.

최종 특징 맵이 7x7로 비교적 거칠기(coarse) 때문에, 이 그리드보다 작은 객체의 세밀한 특징은 이미 사라진 후입니다.

여러 작은 객체가 하나의 그리드 셀 안에 모여 있으면, YOLOv1은 그 중 하나만 감지하거나 아예 감지하지 못하는 경우가 많았습니다.

이 문제 역시 이후 버전에서 다양한 크기의 특징 맵을 함께 사용하는 **FPN(Feature Pyramid Network)**과 같은 구조를 도입하며 크게 개선됩니다.

5. YOLOv1의 출력과 후처리 📝
출력 텐서 (S, S, Bx5 + C)의 의미
YOLOv1의 최종 출력은 (S, S, B*5 + C) 형태의 텐서(Tensor)입니다. (질문 주신 Bx2+C는 Bx5+C가 맞습니다.) 기본 설정인 S=7, B=2, C=20(PASCAL VOC 데이터셋 기준)일 때 출력은 (7, 7, 30)이 됩니다.

S (Grid Size): 이미지를 S x S 개의 그리드 셀로 나눕니다. (e.g., S=7)

B (Bounding Boxes): 각 그리드 셀이 예측하는 바운딩 박스의 수. (e.g., B=2)

C (Classes): 모델이 구분해야 할 객체의 클래스 수. (e.g., C=20)

(7, 7, 30) 텐서에서 각 30차원 벡터의 의미는 다음과 같습니다.

5개 값 (첫 번째 박스): (x, y, w, h, confidence_score)

5개 값 (두 번째 박스): (x, y, w, h, confidence_score)

20개 값 (클래스 확률): 이 그리드 셀에 객체가 있을 경우, 그 객체가 20개의 각 클래스에 속할 확률. (e.g., [P(개), P(고양이), P(자동차), ...])

중요: 클래스 확률은 그리드 셀 당 하나만 계산됩니다. 즉, 한 그리드 셀은 여러 개의 박스를 예측할 수 있지만, 모든 박스가 단 하나의 클래스를 공유합니다.

예측된 여러 박스 정리: 비최대 억제 (Non-Max Suppression, NMS)
YOLO는 수많은 바운딩 박스를 예측하는데, 이 중 대부분은 중복되거나 신뢰도가 낮습니다. NMS는 가장 확실한 박스 하나만 남기고 나머지를 제거하는 과정입니다.

특정 임계값(Threshold) 이하의 신뢰도(confidence score)를 가진 박스를 모두 제거합니다.

남은 박스들 중 신뢰도가 가장 높은 박스를 선택합니다.

선택된 박스와 나머지 박스들의 **IoU(Intersection over Union)**를 계산합니다.

계산된 IoU가 특정 임계값(e.g., 0.5) 이상인 박스들(즉, 선택된 박스와 많이 겹치는 박스)을 모두 제거합니다.

남아있는 박스들에 대해 2~4번 과정을 반복합니다.

박스 예측 정확도 측정: IoU (Intersection over Union)
IoU는 모델이 예측한 바운딩 박스(Predicted Box)가 실제 정답 박스(Ground Truth Box)와 얼마나 정확하게 겹치는지를 0과 1 사이의 값으로 나타내는 지표입니다.

[IoU 다이어그램 이미지]

IoU= 
합집합영역(Area of Union)
교집합영역(Area of Overlap)
​
 
IoU = 1이면 예측과 정답이 완벽히 일치하는 것이고, IoU = 0이면 전혀 겹치지 않는 것입니다.

보통 IoU가 0.5 이상이면 '올바르게 예측했다(True Positive)'고 판단합니다.

6. 객체 탐지 모델의 종합 성능 평가 기준: mAP 🏆
모델의 종합적인 성능은 **mAP(mean Average Precision)**로 평가합니다. mAP를 이해하기 위해서는 **정밀도(Precision)**와 **재현율(Recall)**을 먼저 알아야 합니다.

정밀도 (Precision): 모델이 "객체라고 예측한 것들" 중에서 "실제로 객체인 것"의 비율. (모델의 예측이 얼마나 정밀한가?)

재현율 (Recall): "실제 정답 객체들" 중에서 "모델이 찾아낸 것"의 비율. (모델이 얼마나 빠짐없이 잘 찾아내는가?)

**AP (Average Precision)**는 하나의 클래스에 대한 성능을 나타냅니다. 모델의 신뢰도 임계값을 바꿔가면서 얻어지는 정밀도-재현율 곡선(Precision-Recall Curve)의 아래쪽 면적으로 계산되며, 0과 1 사이의 값을 가집니다. 값이 1에 가까울수록 성능이 좋은 모델입니다.

**mAP (mean Average Precision)**는 모든 클래스의 AP 값에 대한 평균입니다. 즉, 모델이 모든 종류의 객체에 대해 전반적으로 얼마나 뛰어난 성능을 보이는지를 나타내는 최종 성적표와 같습니다.
