## 합성곱 신경망 (Convolutional Neural Network, CNN)

- CNN의 구조: CNN은 이미지의 공간적 구조 정보를 보존하면서 특성을 추출하기 위해 설계된 신경망. 주로 합성곱(Convolution) 층과 풀링(Pooling) 층으로 구성됨
- 합성곱 층: 커널(필터)을 이미지 위에서 이동시키며 합성곱 연산을 수행하여 **특성 맵(feature map)**을 생성함 이는 이미지의 지역적 특성을 추출하는 역할을 함
- **스트라이드(stride)**는 커널의 이동 간격을, **패딩(padding)**은 출력 크기를 조절하기 위해 입력 이미지 가장자리에 값을 채우는 기법
- 풀링 층: 특성 맵의 크기를 줄여(다운샘플링) 계산량을 감소시키고, 주요 특성을 강조하고 주로 **최대 풀링(Max Pooling)**이 사용됨

## 전이학습 (Transfer Learning)

- 대규모 데이터셋(예: ImageNet)으로 이미 학습된 모델(Pre-trained Model)을 가져와 새로운 문제 해결에 활용하는 기법이고 데이터가 부족한 경우에 특히 효과적
- 특성 추출 (Feature Extraction): 사전 학습된 모델의 합성곱 층은 동결(학습되지 않도록 고정)하고, 마지막 분류기 부분만 새로운 데이터에 맞게 재학습시킴
- 미세 조정 (Fine-tuning): 특성 추출 방식에서 더 나아가, 모델의 상위 몇 개 합성곱 층의 동결을 해제하여 새로운 데이터에 더 적합하도록 가중치를 미세하게 조정하며 학습함
