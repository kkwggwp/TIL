# CSS
## 1. font
```
<!-- 
        외부 폰트 적용 방법
        1. link 태그 이용
        2. style 태그에서 @import를 이용하는 방법
        3. style 태그에서 @font-face를 직접 입력하는 방법

        가장 추천하는 방법은 link 태그 이용
        만약 3번의 방식으로 폰트를 제공받았으면,
        css파일을 따로 만들어 link를 통해 css파일을 불러오는 방식을 쓰는게 좋음(브라우저 캐싱)
-->
/* 
            font 관련 css
            font-family : 폰트를 지정, 여러개 지정시 왼쪽부터 지정
            font-size : 폰트 크기를 지정(px, em, rem 등)
            font-weight 폰트의 굵기 지정(100~900, normal(400) bold(700))
            font-style : 폰트의 스타일 지정 (italic, oblique 등)

            px : 화면상의 픽셀 크기에 대응하는 단위(고정값)
            em : 부모요소의 폰트크기를 기준으로 배수로 작용
            rem : html요소의 폰트 크기를 기준으로 배수로 적용(기본값 16px)
        */
```
