# CSS
## 1. 선택자
```
/* 
            계층선택자
            1. 자손 선택자(Descendent Selector)
                div p {color:white;}
                div 태그의 모든 자손 중 p 태그를 선택해 글자를 흰색으로 변경
            2. 자식 선택자(Chile Selector)
                div > p {color:white;}
                div 태그의 모든 자식 중 p 태그를 선택해 글자를 흰색으로 변경
            3. 형제 선택자(Sibling Selector)
                div~p {color:white;}
                div 태그의 인접한 모든 형제 p 태그를 선택해 글자를 흰색으로 변경
            4. 인접형제 선택자(Adjacent Sibling Selector)
                div+p {color:white;}
                div 태그의 인접한 형제 중 첫번째 p태그를 선택해 글자를 흰색으로 변경            
        */
        /* 
            CSS 명시도(Specificity) : CSS 우선순위를 결정
            1. 전체 선택자 : 0
            2. 태그 선택자 : 1
            3. 클래스 선택자 : 10
            4. 아이디 선택자 : 100

            계층 선택자의 경우, 사용된 각각의 선택자들의 명시도를 더한 값
            우선순위는 점수가 높은 선택자
        */
```

## 2. display
```
        /* 
            display: block (div, p, table, h1~h6, ul, ol, li 등)
            가로 영역 한줄 차지
            width, height, margin, padding 설정 가능
            
            display: inline (span, a, img, lable 등)
            내가 담은 영역까지만 차지
            width, height, margin, padding 설정 불가

            display: inline-block (input 등)
            inline처럼 내가 담은 영역까지만 차지하지만 block처럼 속성 설정 가능
        */
```
