## 그레이스케일(Grayscale)

평균값 변환 : B, G, R 채널의 평균을 계산하여 그레이스케일로 변환

cv2.cvtColor(): OpenCV에서 제공하는 함수를 사용하여 더 정확한 그레이스케일 변환이 가능

```Python

img = cv2.imread('./img/bricks.jpeg')
b,g,r = cv2.split(img)
gray1 = ((b+g+r)/3).astype(np.uint8)

img2 = img.astype(np.uint16)
gray2 = cv2.cvtColor(img2, cv2.COLOR_BGR2GRAY)
```

## 스레시홀딩(Thresholding):

이미지를 흑과 백 두 가지 색상으로만 표현하는 이진화(Binarization) 방법
cv2.threshold() 함수를 사용하며, 임계값(threshold)을 기준으로 픽셀 값을 255(흰색) 또는 0(검은색)으로 변환

```Python
img = cv2.imread('./img/bicycle.jpg', cv2.IMREAD_GRAYSCALE)
ret, thresh_cv = cv2.threshold(img, 127, 255, cv2.THRESH_BINARY)
```
