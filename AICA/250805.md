# html
## 1. 목록태그
```
<body>
    <!-- 
        unordered list : 번호가 없는 목록
        ordered list : 번호가 있는 목록
        list item : 목록에 사용되는 아이템 태그
        ol, ul 태그 안에는 반드시 li 태그가 있어야 함
    -->
    <ul>
        <li>HTML</li>
        <li>CSS</li>
        <li>JS</li>
    </ul>

    <ol>
        <li>HTML</li>
        <li>CSS</li>
        <li>JS</li>
    </ol>

    <hr>
    <!-- 
        dl, dt, dd : 용어 정의 태그
        definition list : 용어 정의 목록
        definition term : 정의할 용어
        definition description : 용어 설명
        dl 안에는 만드시 dt, dd가 있어야 함
    -->
    <dl>
        <dt>설명할 용어</dt>
        <dd>상세 설명</dd>
    </dl>
    <!-- 
        ol>li * 3
    <ol>
        <li></li>
        <li></li>
        <li></li>
    </ol>
    -->
</body>
```
