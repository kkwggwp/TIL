# JS 함수
## 1. 함수 선언문
```javascript
function add(a, b) {
  return a + b;
}

// 선언부보다 앞에서 호출 가능(호이스팅)
console.log(add(5, 3)); // 8
```
> 가독성이 좋아 일반적인 함수를 정의할 때 가장 많이 사용됩니다.
> 호이스팅 가능

## 2. 화살표 함수
```javascript
const subtract = (a, b) => a - b;

console.log(subtract(10, 3)); // 7

// 콜백 함수로 사용할 때 매우 유용
const numbers = [1, 2, 3, 4];
const squaredNumbers = numbers.map(num => num * num);
console.log(squaredNumbers); // [1, 4, 9, 16]
```
> 간결한 문법: function 키워드와 return 문을 생략할 수 있어 코드가 짧아짐

> this 바인딩: 자신만의 this를 생성하지 않고, 자신을 감싸고 있는 상위 스코프의 this를 그대로 물려받음. 이 특징 때문에 콜백 함수나 메서드 내에서 this를 다룰 때 매우 편리합니다.

> 생성자 함수(new 키워드)로 사용할 수 없음

## 3. 함수 표현식
```javascript
// 함수 표현식
const multiply = function(a, b) {
  return a * b;
};

console.log(multiply(4, 2)); // 8

// 선언 전에 호출하면 에러 발생
// console.log(multiply(4, 2)); // ReferenceError
// const multiply = function(a, b) { ... };
```
> 호이스팅 불가: 변수 선언 자체(var, let, const)는 호이스팅되지만, 함수 할당은 런타임에 이루어지므로 선언 전에 호출할 수 없습니다.

> 콜백 함수나 클로저(Closure)를 정의할 때 유용하게 사용됩니다.
