# nodeJS
## 1. db 연결
```javascript
const mysql = require('mysql2/promise');

// Connection Pool 생성
const pool = mysql.createPool({
    host: '127.0.0.1',
    user: 'testuser',
    password: '12345',
    port: 3306,
    database: 'mynode',
    waitForConnections: true,
    connectionLimit: 10,
    queueLimit: 0
});

module.exports = pool;
```
mysql2/promise를 활용한 pool 방식
