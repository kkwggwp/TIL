## 블러링 (Blurring):

커널 (Kernel): 이미지에 적용되는 필터로, 행렬 형태로 정의됨

다양한 블러링 기법:

- 단순 블러 (Simple Blur): cv2.blur() 또는 cv2.boxFilter()를 사용하여 커널 내 픽셀 값의 평균을 계산

- 가우시안 블러 (Gaussian Blur): cv2.GaussianBlur()를 사용하여 가우시안 분포를 이용한 커널을 적용, 노이즈 제거에 효과적

- 미디언 블러 (Median Blur): cv2.medianBlur()를 사용하여 커널 내 픽셀 값의 중간값을 사용함. 소금-후추 노이즈(salt-and-pepper noise) 제거에 탁월

```Python

import cv2
import numpy as np

img = cv2.imread('../img/girl.jpg')

# 가우시안 블러
blur3 = cv2.GaussianBlur(img, (3, 3), 0)

# 미디언 블러
blur = cv2.medianBlur(img, 5)
```
## 샤프닝 (Sharpening):

블러링된 이미지와 원본 이미지의 차이를 이용하여 경계를 강조하는 기법
샤프닝 커널을 직접 정의하여 cv2.filter2D() 함수에 적용 가능

```Python

# 샤프닝 커널
k = np.array([[-1, -1, -1],
              [-1,  9, -1],
              [-1, -1, -1]])

sharpen = cv2.filter2D(img, -1, k)
```
