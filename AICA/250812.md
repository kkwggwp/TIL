# CSS
## 1. 포지션
position : relative
- 현재 위치를 기준으로 top, left, bottom, right로 이동
- 양수값 입력 : x축 기준으로 오른쪽, y축 기준으로 아래쪽

position : absolute
- 요소를 문서의 흐름에서 제거하고, 기준이 되는 부모요소를 기준으로 절대 위치로 이동
- 부모가 static인 경우만 그 상위 부모요소를 기준으로 함(body까지 감)

z-index : 정수
- 양수일수록 위, 음수면 아래(기본값 : auto)
- 적용되려면 position이 static이 아니어야함

position : sticky
- 요소가 문서의 흐름에 따라 스크롤되다가 지정한 위치를 만나면 화면에 고정됨
- 고정 기준점은 스크롤이 가능한 가장 가까운 조상 요소
- 부모 요소를 벗어나지 못함
- 반드시 좌표가 하나 이상 설정되어야함
            
position : fixed
- 요소를 문서의 흐름에서 제거, 화면 기준으로 고정됨
- 스크롤을 하더라도 항상 같은 화면 위치에 머무름
- 기준점은 브라우저 화면

## 2. overflow
overflow : 요소의 컨텐츠가 요소의 크리를 초과할때 처리 방법
- visible : 영역 벗어나도 다 보여줌(기본값)
- hidden : 영역을 벗어난 부분을 숨김
- scroll : 컨텐츠가 넘치든 아니든 스크롤바를 만들어 처리
- auto : 컨텐츠가 넘치면 스크롤바 표시, 아니면 숨김
            
overflow-x, overflow-y를 통해 한 축의 overflow만 지정 가능

## 3. flex
display: flex (레이아웃 배치 전용 기능)
- container : 부모 요소로 flex의 영향을 받는 전체 공간
- item : 설정된 flex 속성에 따라 배치되는 자식 요소

1. flex container 속성
flex-direction: 아이템이 배치되는 축의 방향 결정
- row : 가로 (기본값)
- row reverse : 가로 역순
- column : 세로
- column reverse : 세로 역순

flex-wrap: 아이템의 줄바꿈을 결정하는 속성
- nowrap : 줄바꿈 x (기본값)
- wrap : 줄바꿈 o
- wrap-reverse : 줄바꿈 o, 역순

justify-content : 메인축 방향 아이템 정렬
- flex-start : 시작점 정렬(기본값)
- flex-end : 끝점
- center : 중앙
- space-between : 아이템 사이 균일한 여백
- space-evenly : 아이템 사이와 양 끝 균일한 여백
- space-around : 아이템 둘레 균일한 여백

align-items : 교차축 방향 아이템 정렬
- stretch : 컨테이너 교차축 방향으로 아이템 늘림(기본값)
- flex-start : 시작점 정렬
- flex-end : 끝점 정렬
- center : 중앙 정렬
- baseline : 텍스트 기준선을 기준으로 정렬

2. flex item 속성
- flex-grow : container의 남은 공간을 n의 비율로 분배(기본값 0)
- flex-shrink : container의 남은 공간이 부족할 때, 줄어드는 비율 결정(기본값 1)
- flex-basis : item의 기본 크기 설정, 메인 축 방향 (기본값 auto)
- flex : flex-grow, flex-shrink, flex-basis 값을 한번에 설정 (순서 유의)
