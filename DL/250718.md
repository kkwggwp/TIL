### 신경망 설계 방식의 차이
## 1. nn.Sequential을 Class 없이 사용
```
model2 = nn.Sequential(
    nn.Linear(input_size, 500),
    nn.ReLU(),
    nn.Linear(500, 400),
    nn.ReLU(),
    nn.Linear(400, 300),
    nn.ReLU(),
    nn.Linear(300, 200),
    nn.ReLU(),
    nn.Linear(200, 100),
    nn.ReLU(),
    nn.Linear(100, 50),
    nn.ReLU(),
    nn.Linear(50, output_size),
    nn.LogSoftmax(dim=1)
)
```
1. nn.Sequential을 사용해 모델만 정의한 경우는 코드가 짧고 직관적이지만 유연성이 매우 부족함
2. 아주 간단한 계산을 구현하는 프로토타이핑 아니면 사용을 권장하지 않음

## 2. Class 사용시
```
class MyModel(nn.Module):
    def __init__(self, input_dim, output_dim):
        super().__init__()
        self.input_dim = input_dim
        self.output_dim = output_dim
        self.model = nn.Sequential(
            nn.Linear(input_size, 500),
            nn.ReLU(),
            nn.Linear(500, 400),
            nn.ReLU(),
            nn.Linear(400, 300),
            nn.ReLU(),
            nn.Linear(300, 200),
            nn.ReLU(),
            nn.Linear(200, 100),
            nn.ReLU(),
            nn.Linear(100, 50),
            nn.ReLU(),
            nn.Linear(50, output_size),
            nn.LogSoftmax(dim=1)
        )  
    def forward(self, X):        
        return self.model(X)

model = MyModel(input_dim=input_size, output_dim=output_size)
```
1. 높은 유연성을 가짐
